# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple Bash-based project that calculates simple interest using the principal amount, annual rate of interest, and time period provided by the user.

## Formula

Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal:** The initial amount of money.
* **Rate:** The annual rate of interest in percentage.
* **Time:** The time period in years.

## Features

* Accepts the principal amount from the user.
* Accepts the annual rate of interest.
* Accepts the time period in years.
* Calculates simple interest using the formula.
* Displays the calculated simple interest.

## Requirements

* Bash shell
* A terminal to execute the script

## How to Run

1. Clone or download this repository.

2. Open a terminal in the project directory.

3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

5. Enter the principal amount, rate of interest, and time period when prompted.

## Example

Suppose the inputs are:

* Principal: 1000
* Rate: 5%
* Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Output:

```text
Simple Interest: 100
```
