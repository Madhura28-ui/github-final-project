# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## Welcome Contributions

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Push your branch to your forked repository.
6. Open a pull request describing your changes.

## Reporting Bugs

If you find a bug, please report it by opening an issue. Include a clear description of the problem and the steps required to reproduce it.

## Suggesting Improvements

Suggestions for new features, improvements, and documentation are welcome. Please explain your idea clearly so that others can understand its benefits.

## Code Guidelines

* Keep the Bash script simple and readable.
* Use meaningful variable names.
* Test your changes before submitting them.
* Update the documentation when necessary.

## Thank You

Thank you for helping improve the Simple Interest Calculator project!
